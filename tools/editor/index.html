Playing your track

Save the file as designs.ebd next to the game, start excitebike, choose DESIGN, then LOAD, and run the track. Tracks over 255 bytes are saved in the extended format (the port plays them with no length limit; the original game's 236-byte limit does not apply). The port can also reload the file while it runs (F6).
