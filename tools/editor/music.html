Excitebike Music Editor

Click an empty spot to add a note, click a note to select it, drag its right edge to resize, drag its body to move it; Delete removes it, arrow keys nudge it (left/right = time, up/down = pitch). Notes in a voice cannot overlap.

Selected note

The port plays the saved file with --audio-mod DIR (the file must be named song_XX.ebm). F6 reloads it while the game runs. Frames are 1/60 s.
